# Skill decisions

## Kept as workflow stages

- Turn Up Time — one root control plane.
- OmniDex — evidence compiler and ticket factory.
- Boil the Ocean — ticket execution only.
- Easily Irritated — independent product closeout.
- Production Audit — operational readiness followed by a separate fresh release judge.
- Its Not You, Its Me — evidence-gated workflow improvement.

## Kept as conditional controls

- Grill Me — human-owned ambiguity only.
- Guard Before Write — consequential-action gate and receipt.
- Plug It In — provider placement, conflict, eval, and removal contract.

## Kept as an internal provider

- Eval Harness — seeded and product eval grammar; not a second lifecycle.

## External provider strategy

- Impeccable is the preferred frontend provider, routed by capability and mode (`operate`, `persuade`,
  `read`, `experience`). It is not vendored or always-loaded.
- Taste is not a dashboard/product-interface default. Useful Design Read and anti-default principles may
  be retained as an optional reference lens.
- E2E Testing provides browser/journey verification.
- AI Regression Testing provides model/agent behavior regression coverage.
- Provider availability, stage, conflicts, authority, eval, and uninstall are resolved through
  `.claude/capabilities/registry.json` and `resolve_capabilities.py`.

## Retired from the default flow

- Engineering Loop.
- Default OmniDex R0–R3 consensus rounds.
- Default Boil fan-out and unlimited judge loops.
- Verification Loop as a second release constitution.
- UI/UX Pro Max as mandatory frontend instructions.
- Design System and Design Review as overlapping workflow constitutions.
- Continuous Learning as an automatic policy writer.
- Fleet coordination/twin-nem unless a real concurrent fleet returns.
- Duplicate YAML/JSON representations of the same machine contract.

## Role design rule

Agents are either:

- **production** — narrow approved Edit/Write scope; or
- **assurance** — read-only by tool list.

Control roles remain in the root session. Every agent has an explicit mission, inputs, procedure, output
contract, stop/escalation, and boundaries.
