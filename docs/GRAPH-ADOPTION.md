# Graph adoption and pilot contract

## What is graph-controlled

For Tier C projects, the graph controls:

- legal stages and events;
- human approvals;
- bounded loop traversals;
- target-stage validation;
- ledger mutation;
- SQLite checkpoint and resume;
- append-only event history.

## What remains agent-controlled

Within an approved node, Claude Code agents retain judgment over:

- research strategy within the lane contract;
- architecture within ratified requirements;
- implementation inside an approved ticket;
- evidence collection and defect investigation;
- review findings inside the approved rubric.

The graph does not automatically launch headless coding agents in v1.0. It is the transition and
recovery authority. This preserves the already-working gauntlet while making shortcuts and unbounded
loops mechanically impossible.

## First real pilot

Use one Standard-profile dashboard or application project. Record:

- time to Intake Ready;
- discovery spawns and research claims rejected;
- ticket revisions before build;
- ticket and integration repair counts;
- Easily Irritated S0-S2 findings;
- post-build scope changes;
- total human gates;
- elapsed time and model cost per stage;
- illegal transition attempts or recovery events.

Feed the results into `/its-not-you-its-me`. A future move to automated worker dispatch or Temporal
requires evidence from this pilot rather than framework enthusiasm.
